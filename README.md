# סופ״ש בטבע

אתר סטטי שמתכנן סופ״ש של **חניון לילה + מסלול הליכה** לפי אזור, לינה בתשלום או בחינם, משפחות, זמן, קושי ומסלול מעגלי.

הנתונים נסרקים מהאתר הציבורי של [רשות הטבע והגנים](https://www.parks.org.il/): חניוני לילה בתשלום, חניוני לילה בלי תשלום, ומסלולי הטיול. מסלולי אופניים, ג׳יפים ורכב מסוננים החוצה.

לפני יציאה לשטח צריך לאמת באתר הרשמי שהמסלול פתוח, שהחניון פנוי, ומה המחיר העדכני. בחניונים בתשלום הלינה בהזמנה מראש, והכניסה עם כלבים אסורה.

## צפייה מקומית

```bash
python3 -m http.server 8000
```

ואז לפתוח [http://127.0.0.1:8000](http://127.0.0.1:8000).

## GitHub Pages

ב־Settings → Pages לבחור את הענף `main` ואת התיקייה `/ (root)`.

## רענון הנתונים

```bash
python3 scripts/fetch_inpa.py
python3 -m unittest discover -s tests
node tests/test_plan.js
```

הסורק קורא את ממשק הוורדפרס הציבורי של האתר וכותב את `data/camps.json`, `data/trails.json` ו־`data/meta.json`.
